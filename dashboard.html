How this works
Claude uses the working directory in the transcript. Grok uses the folder name under ~/.grok/sessions, which is the project path. Other CLI agents still do not record a project path. Sessions whose directory was not captured land in "Unattributed" rather than silently dropping. The account menu above filters these rows. Long paths are shortened; the full path is on the row tooltip.
