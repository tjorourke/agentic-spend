How this works
This splits spend by the Claude account that incurred it, using the account id each Claude Code session transcript already carries. Other CLI agents (Codex, Grok, OpenCode) do not record an account in their logs, so their spend is listed separately below, not attributed. Claude sessions are attributed to their last-active day, so the range picker above matches the other tabs but is approximate for sessions that span midnight. Dollar figures on this page are USD list price. Usage credits further down use the account's own currency and include the currency code. Grok CLI sessions do not record the account. A session updated after this app last looked is tagged with whoever is signed in to the grok CLI then. Older sessions stay "Unattributed Grok account" until you name them here. Claude plan-limit figures come from claude.ai Settings, Usage, cached locally by Claude Code. An account is only refreshed while Claude Code is logged into it, so a switched-away account shows its last-known snapshot.

Spend per repo for Claude Code and the Grok CLI.
How this works
Claude uses the working directory in the transcript. Grok uses the folder name under ~/.grok/sessions, which is the project path. Other CLI agents still do not record a project path. Sessions whose directory was not captured land in "Unattributed" rather than silently dropping. The account menu above filters these rows. Long paths are shortened; the full path is on the row tooltip.
